### 🚀 O que eu faço?

* 🏗️ **Infraestrutura como Código (IaC):** Provisionamento com Terraform e gerência de configuração com Ansible, garantindo ambientes reprodutíveis e sem *configuration drift*.
* 🔐 **DevSecOps / Shift Left:** Esteiras de CI/CD com *quality gates* de segurança — varredura de segredos, SAST, análise de dependências e DAST antes de ir para produção.
* 🐳 **Containerização:** Empacotamento de aplicações com Docker (multi-stage builds, imagens distroless) e orquestração de microsserviços.
* ⚙️ **Pipelines & CI/CD:** Automação de build, teste e deploy com GitHub Actions e Jenkins.
* 💻 **Desenvolvimento Web:** APIs REST seguras (Java/Spring Boot, Node.js) e interfaces com React.
